\# Changelog



\## \[1.0.0] - 2026-05-14



\### Added

\- Initial public release.

\- Multi-threaded path enumeration for osTicket filesystem attachments.

\- Configurable prefix length, directory depth, threads, timeout, retries.

\- HTTP proxy, custom User-Agent, TLS verify toggle, HEAD/GET selection.

\- Status code matching/filtering, minimum size threshold.

\- TSV output, dry-run mode, verbose logging.

\- Interactive fallback prompts.
